# Chat App - Registration, Login and Messaging

By Mitchelle Lerato

This project lets a user rRegister (username, password and cell number), log in, and then send, discard or store messages. Stored messages are saved in a JSON file. It also has unit tests for each check, and GitHub Actions runs the tests when I push my code.
